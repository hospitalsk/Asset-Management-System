# ระบบบริหารจัดการครุภัณฑ์ โรงพยาบาลสังขละบุรี
## Hospital Asset Management System - Sangkhlaburi Hospital

เว็บแอปพลิเคชันสำหรับบริหารจัดการ บันทึก ตรวจสอบ ติดตาม และรายงานข้อมูลครุภัณฑ์ของ **โรงพยาบาลสังขละบุรี**
- **ฐานข้อมูลหลัก**: Supabase (Database & Storage Bucket `asset-images`)
- **Frontend**: Single Page Application รองรับการโฮสต์ผ่าน GitHub Pages
- **In-Memory Fallback**: รองรับการเปิดใช้งานและทดสอบระบบได้ทันทีแบบ In-Memory Demo เมื่อยังไม่ได้เชื่อมต่อฐานข้อมูล

### 2. การออกรายงานและงานพิมพ์
- 📄 **PDF A4 แนวตั้ง (Portrait)**:
  - จัดทำเป็นเอกสารราชการไทย
  - ฝังรูปภาพ Thumbnail ครุภัณฑ์จริง (40–50px) ลงในตาราง
  - มีข้อมูลสรุปจำนวนรายการ มูลค่ารวม และช่องลงนาม 3 ฝ่าย (ผู้จัดทำ, ผู้ตรวจสอบ, ผู้อนุมัติ)
  - ส่งออกเฉพาะรายการที่กำลังกรอง (Filtered items)
- 📊 **CSV Export**:
  - รองรับ UTF-8 BOM (`\uFEFF`) ภาษาไทยไม่เพี้ยนเมื่อเปิดใน Microsoft Excel
  - มีคอลัมน์ ImageUrl และรายละเอียดครุภัณฑ์ครบถ้วน
- 🖨️ **ระบบพิมพ์ (Print)**:
  - สไตล์ชีท `@media print` ปรับหน้ากระดาษเป็น A4 Portrait ซ่อน Navbar, Sidebar, ปุ่ม และส่วนควบคุมทั้งหมด

### 3. มาตรฐานความปลอดภัยและข้อกำหนดพิเศษ
- 🛡️ **Zero Local Storage / Session Storage / IndexedDB**: ปฏิบัติตามข้อกำหนดอย่างเคร่งครัด ไม่มีการใช้ Storage ฝั่งไคลเอนต์ ข้อมูลจะบันทึกผ่าน Supabase หรือ In-Memory State
- 🛡️ **No Sticky Header / No Sticky `<th>`**: ปฏิบัติตามข้อกำหนด ไม่มีการใช้ CSS sticky กับ Header หรือหัวตาราง
- 🛡️ **Upload Security**: ตรวจสอบ MIME Type, ป้องกัน Executable, สุ่มชื่อไฟล์ใหม่ด้วย UUID

## 🚀 วิธีการติดตั้งและเชื่อมต่อ Supabase

### ขั้นตอนที่ 1: รันคำสั่ง SQL ใน Supabase
1. ไปที่ Supabase Dashboard -> ไปที่เมนู **SQL Editor**
2. เปิดไฟล์ `schema.sql` ในโครงการนี้ คัดลอกคำสั่งทั้งหมดไปวางแล้วกด **Run**
3. ระบบจะสร้างตาราง `assets`, `categories`, `locations`, `asset_movements`, `maintenance_records`, `audit_logs`, `app_settings` พร้อม Storage Bucket `asset-images` และตัวอย่างข้อมูลครุภัณฑ์เริ่มต้น

### ขั้นตอนที่ 2: ตั้งค่าการเชื่อมต่อในเว็บแอป
สามารถตั้งค่าได้ 2 วิธี:
- **วิธีที่ 1 (ในโค้ด)**: เปิดไฟล์ `js/config.js` และใส่ค่า:
  ```javascript
  SUPABASE_URL: 'https://your-project-ref.supabase.co',
  SUPABASE_ANON_KEY: 'your-anon-public-key',
  ```
- **วิธีที่ 2 (ผ่านหน้าเว็บ)**:
  1. เข้าสู่ระบบเจ้าหน้าที่ (รหัสผ่าน: `skb1234`)
  2. ไปที่แท็บ **ตั้งค่าระบบ**
  3. กรอก Database Project URL และ Database Anon Public Key ในช่องที่กำหนด แล้วกด **บันทึกการตั้งค่า**
